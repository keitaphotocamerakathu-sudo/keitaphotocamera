KEITA PHOTO TOOLS v12

เพิ่ม Watermark Editor ก่อน Export
- อัปโหลดลายน้ำ PNG/JPG/WebP ได้หลายไฟล์ และเพิ่มซ้ำได้โดยไม่มีจำนวนตายตัวในระบบ
- ลากลายน้ำบนภาพตัวอย่างได้อย่างอิสระ
- ย่อ/ขยายลายน้ำด้วยจุดจับมุมขวาล่าง
- เลือกใส่ลายน้ำเฉพาะบางรูปจากคอลัมน์ "ลายน้ำ" ใน Preview
- ในหน้าดูภาพใหญ่มีปุ่ม "ลายน้ำ: ON/OFF" สำหรับรูปนั้น
- รูปที่ไม่ได้เลือกจะไม่ถูกใส่ลายน้ำ
- ลายน้ำถูกวาดหลัง Auto Fine Tune/Resize และก่อน JPEG Export
- Resume จะจำตำแหน่งลายน้ำ รายการลายน้ำ และรูปที่เลือกไว้ใน Browser
