# Sony Video Review Pro

Web app สำหรับคัด ตัด หมุน และใส่ลายน้ำคลิป Sony S&Q แบบ Local โดยโหมดปกติยังคงไม่ Encode ภาพใหม่

## ฟังก์ชันหลัก
- Preview + Story timeline พร้อม thumbnails
- ลากหัว/ท้ายเพื่อเลือกช่วงตัดทุกคลิป
- Auto Trim รอบตำแหน่ง playhead (กำหนดวินาทีก่อน/หลังได้)
- ไปคลิปถัดไปและเล่นอัตโนมัติหลัง Auto Trim
- Rotation แยกแต่ละคลิป + Apply to all
- Review Mode และคีย์ลัด: Space, ←/→, K, X, F, I, O, T, R
- Keep / Reject / Favorite + Filter + Search
- เลือกเฉพาะไฟล์ที่ต้องการ Export
- วิเคราะห์ Keyframes และแสดง marker บน timeline
- Snap จุดเริ่ม/จบไปยัง Keyframe
- Preset S&Q แนวตั้งขวา/ซ้าย/แนวนอน
- ตั้งชื่อ Output แบบ `ชื่อเดิม_PSE[รหัสช่างภาพ]_[เลขรัน]` เช่น `C0001_PSE17_001.mp4` โดยกำหนดรหัสช่างภาพและเลขรันเริ่มต้นได้
- เลือกโฟลเดอร์ปลายทาง Export เอง หรือใช้ `Output/` ในโฟลเดอร์ต้นฉบับ
- Export Queue + Retry เฉพาะไฟล์ที่ล้มเหลว
- S&Q Video-only lossless trim: copy เฉพาะ video stream และตัด audio/data ออก

## วิธีเปิดบน Mac
ในโฟลเดอร์นี้รัน:

```bash
python3 -m http.server 8080
```

จากนั้นเปิด Chrome/Edge ที่:

`http://localhost:8080`

> ครั้งแรกที่ใช้ Trim/Keyframe analysis ต้องมีอินเทอร์เน็ตเพื่อโหลด FFmpeg WebAssembly core จาก CDN แต่ไฟล์วิดีโอไม่ได้ถูก upload ออกไป

## หมายเหตุ Lossless
การตัดใช้ `-c:v copy` จึงไม่ Encode H.264 ใหม่ จุดเริ่มอาจขยับไป keyframe ใกล้เคียงหากไม่ได้ Snap ก่อน Export


## การเลือกโฟลเดอร์ Export (Output Fix)

เวอร์ชันนี้ปรับการเลือกปลายทางสำหรับ Chrome/macOS ให้ตรวจสิทธิ์เขียนชัดเจนขึ้น:

1. กด **เลือกโฟลเดอร์ Export** แล้วเลือกโฟลเดอร์ที่ต้องการ
2. หาก Chrome ยังไม่ให้สิทธิ์เขียน จะมีปุ่ม **อนุญาตเขียนโฟลเดอร์** ให้กดอีกครั้ง
3. ระบบทดสอบสิทธิ์เขียนด้วยไฟล์ชั่วคราวขนาดเล็กและลบทิ้งทันที ก่อนยืนยันว่าปลายทางพร้อมใช้งาน
4. หากตัวเลือกโฟลเดอร์ของ Chrome มีปัญหา สามารถลากโฟลเดอร์จาก Finder มาวางในช่องปลายทางได้
5. ถ้าไม่เลือกปลายทางเอง ระบบยังใช้ `Output/` ภายในโฟลเดอร์ต้นฉบับได้ตามเดิม

หมายเหตุ: `showDirectoryPicker()` ต้องถูกเรียกจากการคลิกของผู้ใช้และทำงานใน secure context (HTTPS หรือ localhost) ตามข้อกำหนดของ File System Access API.


## Chrome/macOS: การเลือกโฟลเดอร์ Export
Chrome บล็อกการให้เว็บเข้าถึงโฟลเดอร์ระดับระบบหรือระดับกว้าง เช่น Home, Desktop, Downloads และ root ของไดรฟ์/SSD โดยตรง
ให้สร้างโฟลเดอร์ย่อย เช่น `SonyExport` ภายในตำแหน่งที่ต้องการ แล้วเลือกโฟลเดอร์ย่อยนั้นแทน เช่น `Desktop/SonyExport` หรือ `ExternalSSD/SonyExport`

## รูปแบบชื่อไฟล์ Export

รูปแบบคงที่: `ชื่อเดิม_PSE[รหัสช่างภาพ]_[เลขรัน].mp4`

ตัวอย่างเมื่อรหัสช่างภาพเป็น `17` และเริ่มรันที่ `1`:
- `C0001_PSE17_001.mp4`
- `C0002_PSE17_002.mp4`
- `C0010_PSE17_003.mp4`

รหัสช่างภาพกรอกได้เองบนหน้าเว็บ และเลขรันจะนับเฉพาะไฟล์ที่เลือก Export ตามลำดับไฟล์ในรายการ

## การป้องกันการเปิดเครื่องมือนักพัฒนา

หน้าเว็บดักเมนูคลิกขวา และคีย์ลัดทั่วไป เช่น F12, Ctrl/Cmd+Shift/Option+I/J/C/K และ View Source เพื่อกันการเปิด Inspect แบบทั่วไป อย่างไรก็ตาม เบราว์เซอร์ไม่อนุญาตให้เว็บไซต์ปิด DevTools ได้ 100% ผู้ใช้ที่ตั้งใจยังสามารถเปิดจากเมนูของเบราว์เซอร์หรือวิธีอื่นได้

## Watermark Studio

เพิ่มระบบลายน้ำหลายชิ้นในหน้า Review เดียวกัน:
- เพิ่มไฟล์ PNG / JPG / WebP ได้หลายชิ้น โดยตัวโปรแกรมไม่กำหนดจำนวนสูงสุดตายตัว (จำนวนจริงขึ้นกับ RAM/กำลังเครื่อง)
- มีปุ่มเพิ่มโลโก้ **KEITA PHOTO CAMERA** จากไฟล์โลโก้ที่มากับโปรเจกต์
- ลากลายน้ำบน Preview เพื่อย้ายตำแหน่งอิสระ
- ลากจุดมุมเพื่อย่อ/ขยาย หรือปรับด้วย Slider
- ปรับตำแหน่ง X/Y, ความโปร่งใส และขนาดแยกแต่ละชิ้น
- หมุนลายน้ำได้ 0°, 90°, -90° และ 180° เพื่อใช้งานทั้งแนวนอนและแนวตั้ง
- ทำสำเนา/ลบลายน้ำทีละชิ้นได้
- ตำแหน่งและขนาดใช้สัดส่วนของเฟรม จึงปรับตามคลิปแนวตั้ง/แนวนอนและ Rotation ของแต่ละคลิป

### คุณภาพเมื่อ Export
- **ปิดลายน้ำ:** ใช้ Video Stream Copy (`-c:v copy`) แบบเดิม ไม่มีการ Encode ภาพใหม่
- **เปิดลายน้ำ:** ต้อง Encode H.264 ใหม่เพื่อฝังภาพลายน้ำลงทุกเฟรม โดยตั้งค่า `libx264`, `CRF 16`, `ultrafast`, `yuv420p` และตัด Audio/Data สำหรับคลิป S&Q

ลายน้ำทุกชิ้นใช้ร่วมกับไฟล์ที่เลือก Export ใน Queue นั้น และจะถูกฝังหลัง Rotation จริงของคลิป
