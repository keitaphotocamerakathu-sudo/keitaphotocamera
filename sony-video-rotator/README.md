# Sony Video Rotator & Trimmer

เว็บแอปสำหรับจัดการวิดีโอ Sony A7R III/ไฟล์ MP4-MOV จากหน้าเดียว: Preview, หมุน และเลือกช่วงตัดแยกแต่ละคลิป

## ความสามารถ
- เลือกโฟลเดอร์วิดีโอทั้งโฟลเดอร์ด้วย File System Access API
- Preview คลิปจริงก่อนทำงาน
- หมุน 0°, 90° ขวา, 90° ซ้าย, 180° โดยแก้ transformation matrix เท่านั้น
- เลือกช่วงตัดของแต่ละคลิปด้วย slider หรือใช้ตำแหน่ง playhead เป็นจุดเริ่ม/จุดจบ
- Preview เฉพาะช่วงที่เลือก
- คลิปแต่ละไฟล์จำช่วงตัดของตัวเอง
- Export ไฟล์ทั้งหมดไปที่ `Output/`
- ไฟล์ที่ตัดจะลงท้าย `_cut`
- ตัดแบบ stream copy (`-c copy`) ผ่าน FFmpeg WebAssembly จึงไม่ re-encode video/audio
- วิดีโอไม่ถูก Upload ขึ้นเซิร์ฟเวอร์

## หมายเหตุเรื่อง Lossless Trim
การตัดแบบไม่ re-encode ต้องเริ่มจาก keyframe ดังนั้นจุดเริ่มของไฟล์ Export อาจอยู่ก่อนตำแหน่งที่เลือกเล็กน้อย นี่เป็นข้อแลกเปลี่ยนเพื่อคง video/audio stream เดิมโดยไม่ลดคุณภาพ

ครั้งแรกที่ใช้ฟังก์ชันตัด Browser จะดาวน์โหลด FFmpeg WebAssembly core จาก jsDelivr (`@ffmpeg/core@0.12.10`) แต่ไฟล์วิดีโอของผู้ใช้จะไม่ถูกส่งออกจากเครื่อง

## วิธีทดสอบ
File System Access API ต้องใช้ Secure Context

```bash
cd sony-video-rotator
python3 -m http.server 8080
```

จากนั้นเปิด Chrome/Edge ที่:

`http://localhost:8080`

หรืออัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages


## Story-style trim timeline
- แสดงเฟรมตัวอย่างของวิดีโอเป็นแถวเดียว
- ลากขอบซ้ายเพื่อกำหนดจุดเริ่ม และขอบขวาเพื่อกำหนดจุดจบ
- พื้นที่นอกช่วงที่เลือกจะถูกทำให้มืด
- คลิก/แตะบน timeline เพื่อเลื่อน playhead ไปยังตำแหน่งนั้น
- การลากช่วงตัดจะเปิดโหมดตัดของคลิปนั้นให้อัตโนมัติ
- ปุ่มตั้งจุดเริ่ม/จุดจบแบบเดิมยังคงอยู่เป็นทางเลือก
