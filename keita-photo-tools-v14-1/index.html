W

Watermark — สำหรับ HIGHLIGHT

รูป HL ทุกใบจะใส่ลายน้ำอัตโนมัติ โดยแยกชุดแนวตั้ง / แนวนอน

ระบบใช้รูป HIGHLIGHT เป็นตัวอย่างก่อน
ถ้ายังไม่มี HL จะใช้รูปแรกของแนวนั้น
สลับแท็บ แนวตั้ง / แนวนอน เพื่อจัดชุดแยกกัน · เพิ่ม Event Frame และลายน้ำของช่างภาพได้หลาย Layer · ลากเพื่อย้ายตำแหน่งและลากจุดมุมขวาล่างเพื่อย่อ/ขยาย · รูป HIGHLIGHT ทุกใบจะใช้ชุดตามแนวภาพอัตโนมัติ
ลายน้ำแนวตั้ง
แต่ละแนวมี Layer แยกกัน เพิ่มได้เรื่อย ๆ และจัดตำแหน่งคนละแบบได้
กำลังแก้ชุดแนวตั้ง · รูป HL แนวตั้งจะใช้เฉพาะ Layer ชุดนี้
ยังไม่มีลายน้ำแนวตั้ง
HIGHLIGHT ที่จะใส่ลายน้ำ 0 รูป
ไม่ต้องเลือกทีละรูป: รูปที่เป็น HIGHLIGHT จะถูกใส่ลายน้ำอัตโนมัติทั้งหมด ส่วนรูปขายหลักจะไม่มีลายน้ำ

Export

ทดสอบ 1 รูปก่อน แล้วจึง Export ทั้งอัลบั้ม

Folder Exportยังไม่ได้เลือก — ระบบจะสร้าง KEITA_EXPORT_วันที่_เวลา
Export จะสร้าง 3 แฟ้มอัตโนมัติ: ภาพขายทั้งหมด + HL มีลายน้ำ + HL ไม่มีลายน้ำ
01_ALL_PHOTOS = ภาพทั้งหมดที่ Export แบบไม่มีลายน้ำ · 02_HIGHLIGHT_WATERMARK = รูป HL แบบมีลายน้ำ · 03_HIGHLIGHT_CLEAN = รูป HL ชุดเดียวกันแบบไม่มีลายน้ำ
