2) ตั้งค่า Supabase License Backend

ใช้ Supabase Free เฉพาะสถานะ Activation ใช้ครั้งเดียว URL และ anon key เป็นข้อมูล public ได้ ส่วน Admin Secret ห้ามเผยแพร่

ให้รันไฟล์ supabase/keita-license-schema.sql ใน Supabase ก่อนใช้งาน

3) Publish Public Key + Config ไป GitHub

อัปโหลดเฉพาะ Public Key และ Supabase URL/anon key ขึ้นเว็บ ไม่มี Private Key และไม่มี Admin Secret

ยังไม่ได้ Publish

4) สร้าง License + ลงทะเบียน One-time Activation

Key ทุกตัวมี 20 ตัวอักษรและบังคับให้มี A–Z / a–z / 0–9 / อักขระพิเศษครบ เมื่อ Activate สำเร็จครั้งแรก Key เดิมจะใช้ซ้ำไม่ได้

รอข้อมูล
Activation Key — ส่งให้ผู้ใช้พร้อมไฟล์ .keita-license

5) จัดการ Activation

หากผู้ใช้ล้าง Chrome แล้ว Key เดิมจะ Activate ซ้ำไม่ได้ตามกติกา 1 ครั้ง เอสสามารถ Reset เอง หรือ Revoke ได้จากตรงนี้
