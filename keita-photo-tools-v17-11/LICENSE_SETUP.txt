KEITA PHOTO TOOLS v17.11 — ONE-TIME ONLINE LICENSE
====================================================

แนวคิด
- สร้าง License จาก license.html
- Activation Key 20 ตัว มีพิมพ์ใหญ่/พิมพ์เล็ก/ตัวเลข/อักขระพิเศษครบ
- Payload ถูกเข้ารหัส AES-256-GCM
- AES key derive ด้วย PBKDF2-SHA256 250,000 รอบ
- License payload เซ็นด้วย ECDSA P-384 / SHA-384
- ผูก Device ID
- Supabase เก็บเฉพาะ SHA-256 hash ของ Activation Key และสถานะ Activated
- Key เปิดใช้งานได้ครั้งเดียวจริง
- หลัง Activate สำเร็จ user.html ใช้ signed local activation cache ต่อได้โดยไม่ต้องเก็บ Activation Key

ไฟล์หลัก
- index.html      หน้าหลักของเอส
- teach.html      ห้องสอน Master AI
- user.html       หน้าสำหรับผู้ใช้ทั่วไป + License Gate
- license.html    สร้าง/จัดการ License
- keita-license-public.json   Public Key (สร้าง/Publish จาก license.html)
- keita-license-config.json   Supabase URL + anon key สำหรับหน้า User
- supabase/keita-license-schema.sql  ตาราง + RPC One-time Activation

ตั้งค่า Supabase ครั้งแรก
1. เปิดไฟล์ supabase/keita-license-schema.sql
2. เปลี่ยนคำว่า CHANGE_THIS_ADMIN_SECRET เป็นรหัส Admin Secret ที่ยาวและสุ่มมาก เช่น 40-60 ตัว
3. Run SQL นี้ใน Supabase SQL Editor ของโปรเจกต์ที่ใช้ License
4. เปิด license.html
5. ใส่ Supabase URL, anon key และ Admin Secret เดียวกับใน SQL
6. กด "ทดสอบ Backend" ต้องขึ้นว่า Backend พร้อมใช้งาน

ตั้งค่ากุญแจ License
1. ใน license.html กด "สร้างกุญแจ P-384 ครั้งแรก"
2. ระบบดาวน์โหลดไฟล์ .keita-key ให้ทันที
3. สำรองไฟล์ .keita-key ไว้อย่างน้อย 2 ที่ และห้ามอัปขึ้น GitHub/ส่งให้ผู้ใช้
4. ใส่ Fine-grained GitHub Token (repo Contents: Read and write)
5. กด "Publish License Config"
6. ระบบจะ Publish:
   - keita-license-public.json
   - keita-license-config.json
   ไม่มี Private Key หรือ Admin Secret ถูก Publish

ออก License
1. ผู้ใช้เปิด user.html แล้วส่ง Device ID ให้เอส
2. ใน license.html กรอก Device ID / ชื่อ / Photographer Code
3. เลือกประเภท:
   - ทดลองใช้ N วัน
   - รายเดือน N เดือน
   - รายปี N ปี
   - กำหนดวันหมดอายุเอง
   - ถาวร
4. กด "สร้าง + ลงทะเบียน + ดาวน์โหลด"
5. ระบบจะ:
   - Gen Activation Key 20 ตัวแบบ crypto-secure
   - ลงทะเบียน hash ของ Key ใน Supabase
   - Download ไฟล์ .keita-license
   - แสดง Activation Key
6. ส่งทั้งไฟล์ .keita-license และ Activation Key ให้ผู้ใช้

ผู้ใช้ Activate
1. เปิด user.html
2. เลือกไฟล์ .keita-license
3. ใส่ Activation Key 20 ตัว
4. กด Activate ครั้งแรก
5. ระบบจะถอดรหัส + ตรวจ ECDSA signature + ตรวจ Device + ตรวจหมดอายุ
6. ติดต่อ Supabase เพื่อตรวจว่า Key ยังไม่เคยใช้
7. ถ้าสำเร็จ Supabase mark Activated และ Key นั้นจะใช้ Activate ซ้ำไม่ได้
8. Browser เก็บ signed activation cache โดยไม่เก็บ Activation Key

กรณีผู้ใช้ Reset Chrome / ล้าง Site Data
- Local activation cache จะหาย
- Key เดิม Activate ซ้ำไม่ได้ตามกฎ one-time
- เอสเปิด license.html > จัดการ Activation > ใส่ License ID > Reset Activation
  หรือออก License ใหม่ก็ได้

ความปลอดภัย
- Supabase DB ไม่เก็บ Activation Key แบบ plain text เก็บ SHA-256 hash เท่านั้น
- user.html ไม่มี Private Key และไม่มี Admin Secret
- license.html เก็บ Admin Secret ใน sessionStorage เท่านั้น
- GitHub มีเฉพาะ Public Key + Supabase URL/anon key ซึ่งเผยแพร่ได้
- ไม่มีระบบเว็บ JavaScript ใดกันการแก้ source ได้ 100% แต่โครงสร้างนี้ป้องกันการเดา Key/ปลอม License/ใช้ซ้ำได้ดีกว่า Offline-only มาก
