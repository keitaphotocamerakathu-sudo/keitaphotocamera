KEITA PHOTO TOOLS
Batch Rename & EXIF Date Fix

เวอร์ชันนี้เน้นใช้งานกับไฟล์ JPEG/JPG จากกล้อง Sony ของเอส
และทดสอบกับไฟล์จริง Sony ILCE-7RM3 ขนาด 5168 x 3448 แล้ว

ความสามารถ
- เลือกรูปหลายไฟล์ หรือเลือกทั้งโฟลเดอร์
- Batch Rename
  ตัวอย่าง: KPC00001.JPG -> KPC00001PSE17-001.JPG
- เปลี่ยนวันที่ แต่เก็บเวลาเดิมของแต่ละรูป
- กำหนดวัน/เวลาเริ่มต้นใหม่ และรักษาระยะเวลาระหว่างภาพเดิมได้
- เลื่อนวัน/เวลาแบบ Offset (+/- วัน ชั่วโมง นาที วินาที)
- แก้ Time Zone เช่น +08:00 -> +07:00 โดยไม่เลื่อนเวลาในรูป
- Preview ก่อน Export
- สร้างโฟลเดอร์ KEITA_EXPORT_YYYYMMDD_HHMMSS ใหม่อัตโนมัติ
- ไม่เขียนทับไฟล์ต้นฉบับ

วิธีรักษาคุณภาพ
- ระบบไม่ Decode / Encode JPEG ใหม่
- ไม่มี Resize
- ไม่มีการแต่งภาพ
- แก้เฉพาะตัวอักษร ASCII ใน EXIF DateTime/OffsetTime ที่มีอยู่เดิม
- ความยาวของไฟล์ไม่เปลี่ยนจากการแก้ metadata แบบนี้
- metadata อื่น เช่น Sony MakerNote ไม่ถูกสร้างใหม่ทั้งก้อน

ผลการทดสอบกับ KPC00001.JPG จริง
- ต้นฉบับ: 5168 x 3448
- DateTimeOriginal เดิม: 2026:08:30 17:32:27
- OffsetTimeOriginal เดิม: +08:00
- ทดสอบแก้เป็นวันที่ 2026:09:03 และ +07:00
- ขนาดไฟล์ก่อน/หลังเท่ากัน
- พิกเซลภาพก่อน/หลังเหมือนกันทุกพิกเซล

การเปิดใช้งาน
วิธีที่ 1: GitHub Pages (แนะนำสำหรับใช้งานจริง)
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository
2. เปิด GitHub Pages
3. เปิดหน้าเว็บด้วย Chrome หรือ Edge

วิธีที่ 2: เปิดบน Mac แบบ localhost
1. เปิด Terminal
2. cd ไปยังโฟลเดอร์นี้
3. รัน: python3 -m http.server 8000
4. เปิด Chrome ไปที่ http://localhost:8000

เหตุผลที่แนะนำ Chrome/Edge
- ปุ่ม Folder Export ใช้ File System Access API (showDirectoryPicker)
- Safari ยังรองรับการเขียนโฟลเดอร์โดยตรงไม่เท่ากัน

ข้อควรระวัง
- ทดลองกับไฟล์สำเนา 2-5 รูปก่อนใช้งานครั้งแรก
- ตรวจ Preview วันที่ก่อน Export ทุกครั้ง
- ถ้าไฟล์ไม่มี DateTimeOriginal/DateTime/OffsetTime อยู่เดิม ระบบจะไม่สร้าง tag ใหม่ แต่จะข้าม field นั้นเพื่อไม่เสี่ยงทำลาย metadata เดิม
