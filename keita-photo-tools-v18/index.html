Watermark — สำหรับ HIGHLIGHT

รูป HL ทุกใบจะใส่ลายน้ำอัตโนมัติ โดยแยกชุดแนวตั้ง / แนวนอน

ระบบใช้รูป HIGHLIGHT เป็นตัวอย่างก่อน
ถ้ายังไม่มี HL จะใช้รูปแรกของแนวนั้น
สลับแท็บ แนวตั้ง / แนวนอน เพื่อจัดชุดแยกกัน · เพิ่ม Event Frame และลายน้ำของช่างภาพได้หลาย Layer · ลากเพื่อย้ายตำแหน่งและลากจุดมุมขวาล่างเพื่อย่อ/ขยาย · รูป HIGHLIGHT ทุกใบจะใช้ชุดตามแนวภาพอัตโนมัติ
ลายน้ำแนวตั้ง
แต่ละแนวมี Layer แยกกัน เพิ่มได้เรื่อย ๆ และจัดตำแหน่งคนละแบบได้
กำลังแก้ชุดแนวตั้ง · รูป HL แนวตั้งจะใช้เฉพาะ Layer ชุดนี้
