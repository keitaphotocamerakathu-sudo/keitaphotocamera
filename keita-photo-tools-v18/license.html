1) เชื่อม License API

ใส่ URL ของ Cloudflare Worker และ Admin Secret ที่ตั้งไว้ใน Worker Secret ข้อมูลลับนี้เก็บเฉพาะ session ของหน้าเว็บ ไม่ฝังลงไฟล์

ยังไม่ได้ทดสอบ

2) สร้าง License Key

Key จะถูกสร้างบน Server ด้วย CSPRNG ความยาว 20 ตัว และบังคับให้มี A-Z, a-z, 0-9 และอักขระพิเศษครบทุก Key ระบบเก็บเฉพาะ HMAC-SHA256 ของ Key ไม่เก็บ Key จริง

รอข้อมูล
License Key — ระบบจะแสดง Key จริงเฉพาะตอนสร้างครั้งนี้ กรุณาคัดลอกส่งให้ User

3) จัดการ License

ดูว่า Key ใดถูก Activate แล้ว ผูกกับเครื่องไหน หมดอายุเมื่อไร และ Revoke สิทธิ์ได้เมื่อจำเป็น · Key ที่ Activate แล้วไม่สามารถ Reset ไปใช้เครื่องใหม่

ยังไม่ได้โหลด
สถานะKeyผู้ใช้แผนสร้างActivateหมดอายุDeviceจัดการ
ยังไม่มีข้อมูล
Flow สำหรับ User: ส่งลิงก์ user.html + License Key เท่านั้น → เครื่องแรกที่กรอก Key สำเร็จจะถูกผูกกับ Key นั้นถาวร → เครื่องอื่นใช้ Key เดิมไม่ได้ → หากย้ายเครื่องต้องสร้าง Key ใหม่ → อายุแบบ Trial/รายเดือน/รายปีเริ่มนับจากวัน Activate ครั้งแรก
