KEITA PHOTO TOOLS v13 — Highlight Selector

Workflow
1. เลือกรูป
2. Smart Culling
3. Auto Fine Tune
4. Highlight Selector (หลังแต่งภาพ)
5. Rename / Resize / EXIF
6. Watermark เฉพาะรูปที่เลือก
7. Export

Highlight Selector
- เลือกจากภาพ PASS เท่านั้น
- ประเมินหลัง Auto Fine Tune
- ให้คะแนนความคม แสง/สี Composition และสัญญาณ Story/Moment
- ตั้งจำนวน Highlight ได้ เช่น 20 / 30 / 50 รูป
- Diversity ป้องกัน Burst หรือช่วงเวลาเดียวกันกิน Highlight มากเกินไป
- รูป Highlight สามารถ Pin/ยกเลิกเองจาก Preview หรือหน้าดูภาพใหญ่
- H = เปิด/ปิด Highlight ในหน้าดูภาพใหญ่
- ไม่ถูกเลือก Highlight ไม่ได้หมายถึง Reject และยังขายได้ตามปกติ
- เลือกสร้างสำเนาไฟล์ Highlight ในโฟลเดอร์ HIGHLIGHT ตอน Export ได้
- Resume จำคะแนนและรายการ Highlight

Watermark จาก v12 ยังอยู่ครบ: เลือกใส่เฉพาะบางรูป, หลาย Layer, ลากและย่อ/ขยายได้

แนะนำ Chrome/Edge ผ่าน HTTPS หรือ GitHub Pages สำหรับ Folder/Resume/Export เต็มรูปแบบ
